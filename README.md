# SkillSwap – Student Skill Exchange Platform

SkillSwap is a student skill exchange platform that encourages peer-to-peer learning by allowing students to share skills, explore learning opportunities, manage learning requests, and access a learning chat interface.

## 🚀 Features

- Student dashboard
- Skill exchange and learning requests
- Skill recommendations
- Personalized learning plans
- Learning chat interface
- Chat access for accepted learning requests
- Responsive user interface
- Browser-based local storage

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ▶️ How to Run

1. Download or clone this repository.
2. Open the main project folder.
3. Open `index.html` in your browser to explore the main SkillSwap application.
4. To explore the chat interface separately, open the HTML file inside the `chat` folder.

If the chat interface depends on the main application's data, test it through the main application flow rather than opening it independently.

## 💬 Learning Chat

The project includes a separate chat interface designed for accepted learning requests.

**Current limitation:** The prototype uses browser local storage. Chat messages are not delivered between different users or devices, and the application does not yet provide production-ready authentication or real-time messaging.

## 🔒 Privacy & Security

- Do not enter real passwords or sensitive personal information.
- Local storage is not a secure backend database.
- Production use would require secure authentication, server-side validation, access controls, and appropriate data protection.
