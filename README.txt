SKILLSWAP — STUDENT SKILL EXCHANGE PROTOTYPE
================================================

FILES
- index.html  : page structure and forms
- style.css   : responsive layout and visual styling
- script.js   : interactions, demo sign-in, recommendations and learning plan

HOW TO RUN
1. Extract the ZIP.
2. Keep all three files in the same folder.
3. Open index.html in a modern browser.
4. Enter an email address for demo sign-in.
5. For a first-time email, create a display profile.
6. Add skills, explore listings, request learning, and use Dashboard.

PRODUCT FEATURES
- First-time profile setup and profile editing
- Email address is not rendered on public profile cards
- No mobile number is requested
- Skill listings with search, category and level filters
- Save skills and send/accept/decline learning requests
- Interest-based skill recommendations using simple keyword matching
- Personal learning task planner with target date, priority, checklist and progress
- Profile visibility toggle, report/block demo tools
- Responsive layout and basic public-text validation

IMPORTANT LIMITATIONS
This is a frontend lab/demo prototype. The email is not verified, and there is no real authentication, backend, database, cross-device sync, real-time messaging, moderator inbox, or server-enforced privacy. Browser localStorage can be inspected or changed by someone with access to the browser. Do not use real sensitive information. For a real public product, add verified authentication, backend authorization, server-side validation, secure storage, abuse moderation, privacy policy, and security testing.
