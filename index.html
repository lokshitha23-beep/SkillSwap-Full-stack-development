RESPECT IS REQUIRED

Safety centre

Simple rules to keep student-to-student learning respectful.

🔐

Learn with confidence, not pressure.

You can decline a request, stop an interaction, block a demo profile or submit a report at any time.

◉

Protect your privacy

Use a display name. Do not publish phone numbers, personal email addresses, home addresses, passwords or live location.

✋

Respect boundaries

Learning requests are optional. No one should pressure you to accept, share personal details or meet in person.

⚑

Report concerning behaviour

Report harassment, impersonation, spam, inappropriate content or misleading skill claims. Reports should be reviewed by a moderator in a real deployment.

⊘

Block unwanted contact

Blocking a profile hides it in this local demo. A production platform must enforce blocks on the server too.

SAFETY TOOL

Report a profile or skill

This prototype saves reports only in this browser. It does not send them to a real support team.

Before real public launch: this HTML/CSS/JavaScript prototype is not a secure multi-user service. Real users need backend-enforced access control, verified authentication, private data storage, a moderator workflow, clear policies and security testing.
